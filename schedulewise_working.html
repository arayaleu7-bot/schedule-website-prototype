Import data for all Cal Poly subjects

ScheduleWise does not invent a complete class catalog or pretend that sample courses are live sections. To cover every department, import an authorized course export with columns code,title,section,days,start,end,instructor,units,seats (CSV), or a JSON array of objects with those keys.

Example: CHEM 124,General Chemistry,01,MWF,09:00,09:50,,4,. Sections and seats are only as current as your imported file. No automated scraping or university login is included.

PDF support: The page loads Mozilla PDF.js from a public CDN when you import a PDF. An internet connection is needed for PDF imports; plain text, CSV, HTML and JSON work offline. PDFs containing only scanned images cannot be read without OCR.

Privacy: DPR parsing happens in your browser. Data is saved in localStorage on your device, not sent to a server by this app. Browser extensions and third-party libraries have their own privacy considerations. Clear your data before using a shared computer.
